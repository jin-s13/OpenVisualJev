\section{Experimental setup}
All comparisons use Qwen3-VL-4B-Instruct~\citep{bai_2025_qwen3vl}. Vision parameters are frozen; language attention projections receive LoRA adaptation~\citep{hu_2021_lora}. We compare Set Pointer with a complete-candidate LM that reads all labeled alternatives and directly scores their answer tokens. Both directly output candidate probabilities. The main interface comparison combines candidate-conditioned cross-entropy and the dataset-wise calibration loss, optimized with AdamW~\citep{loshchilov_2017_adamw}. Independent Pointer is included in the relation test to probe the limitation of candidate-independent utilities. It uses independent candidate branches and a shared pointer readout. Section~\ref{sec:order-stability} details the input organization and scoring components of each interface.

The reported accuracy and probability tables were evaluated with ordinary batched branches using the same branch visibility and positional coordinates described in the method.

\paragraph{Unified recognition.}
We train one checkpoint per method across Pets~\citep{parkhi_2012_pets}, CUB, Cars~\citep{krause_2013_cars}, Dogs, Flowers~\citep{nilsback_2008_flowers}, and Aircraft~\citep{maji_2013_aircraft}. The cleaned training, development, and calibration inventories contain 31,088, 3,637, and 3,635 images. The standard test uses 35,566 FOCI-style four-choice records~\citep{geigle_2024_foci} distributed with Finedefics~\citep{he_2025_finedefics}, with identical shuffled candidates for all methods. We retain the author's repeated Dogs test row. Every question includes the gold class and a specified set of distractors, defining conditional multiple-choice classification. We reuse the published evaluation records and train both interfaces with our unified Qwen3-VL protocol.

\paragraph{Main model and component ablation.}
The main recognition and probability comparisons in Tables~\ref{tab:unified-standard} and~\ref{tab:unified-probability} use balanced hard-four-choice training. Each effective batch contains 96 questions, with 16 from each dataset. Both interfaces use seed 20261021 and the fixed epoch-three checkpoint after 2,016 updates, with identical candidate exposures. The full method uses calibration-loss weight five and a separate temperature minimizing equal-dataset calibration NLL. Table~\ref{tab:training-calibration} isolates the training penalty and temperature within Set under this same recipe. Appendix~\ref{sec:training-calibration-protocol} specifies the optimization details.

\paragraph{Natural VQA.}
A separate supervised A-OKVQA experiment~\citep{schwenk_2022_aokvqa} evaluates ordinary task capability on an internal holdout of 2,576 questions, with disjoint training, selection, and calibration roles. We report the native LM comparison across three training seeds. Both interfaces are adapted separately to A-OKVQA. Split and optimization details are in Appendix~\ref{app:essential}.

\paragraph{Metrics.} We report accuracy, NLL, sum-Brier, and ECE. Each model's temperature is fitted only on reserved calibration data~\citep{guo_2017_calibration}. Recognition averages datasets equally. Paired intervals resample image clusters within datasets; relation intervals resample scenes. Appendix~\ref{app:essential} specifies resampling and calibration conventions. Bold values denote the best point estimates in the indicated comparison, including displayed ties.
