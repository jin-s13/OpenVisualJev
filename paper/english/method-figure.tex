Each token attends to its causal predecessors within its branch and to its ancestors. The shared projection is applied independently to each candidate representation; position-free Set attention then compares candidates jointly. The question query bypasses candidate interaction and scores the resulting keys before masked softmax. Each question has its own interaction and normalization. Training includes dataset-wise mean-confidence regularization, followed by held-out temperature scaling.}
