\section{Introduction}
Vision--language models provide a general-purpose foundation for interpreting visual observations through natural-language instructions. Their integration into decision pipelines introduces a distinct inference requirement: converting this semantic understanding into low-latency, machine-consumable judgments. In this setting, the application specifies a decision space at runtime, and the model assigns probabilities to its alternatives. The emerging System One paradigm motivates direct prediction for such judgments, with visual decision models extending this interface to image-conditioned tasks~\citep{yu_2026_visualjev,zhou_2026_pixeljev}. This formulation brings the semantic flexibility of pretrained vision--language models to a structured probabilistic interface.

A central architectural question is how the runtime candidate set should enter the scoring function. Its elements have semantic content, but their presentation order is usually incidental to the decision. At the same time, the appropriate comparison can depend on which alternatives are available. A scorer should therefore preserve candidate identity under reordering while allowing relative preferences to change with the set. These requirements distinguish presentation symmetry from semantic interaction. Independent candidate scores provide the former, while joint comparison supplies the capacity needed for set-dependent decisions. Set representation learning offers a principled foundation for combining these properties~\citep{zaheer_2017_deepsets,lee_2019_set}.

We present OpenVisualJev\footnote{An independently developed research implementation of a Jev-style multimodal decision model.}, a multimodal decision model built on a vision--language backbone with a dynamic candidate-scoring head. The architecture separates visual grounding of individual candidates from comparison within the current set. Tree-masked attention packs shared image and question prefixes with isolated candidate suffixes into one backbone forward. A position-free set module compares the resulting candidate representations, and a shared pointer maps them to a probability distribution over the supplied choices. This composition makes the scoring function permutation equivariant while retaining set-dependent preferences. Calibration-aware training and held-out temperature scaling complete the probability estimation pipeline. Figure~\ref{fig:set-pointer-method} presents the model.

We evaluate order stability and set-dependent preferences through controlled tests, then assess standard recognition and VQA capability on the same Qwen3-VL backbone. The results connect candidate-set structure to stable decisions, stronger recognition with larger difficult candidate sets, and calibrated probability outputs.

Our contributions are threefold:
\begin{itemize}
\item We develop a multimodal decision model that combines pretrained visual--language representations with dynamic candidate scoring and an explicit probability-calibration pipeline.
\item We formulate a candidate-scoring architecture that combines permutation-equivariant set interaction with shared pointer readout, and analyze its order stability and capacity for set-dependent preferences.
\item We evaluate these properties through controlled structural tests, unified fine-grained recognition, and natural VQA, with ablations that characterize candidate interaction, candidate-count training, and probability calibration.
\end{itemize}
